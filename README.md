# Tone Tailored Mail Crafter

Step 1: Zaroori cheezein
• Domain naam (Namecheap ya GoDaddy se, lagbhag 10 se 15 dollar saal ka). Misaal: professionalemailwriter.com ya mailcraftai.com
• Hosting: Netlify ya Cloudflare Pages (free) agar plain website hai. WordPress chahiye to Hostinger ya Bluehost.
• AI tool jo code bana sake: Claude, ChatGPT, Lovable ya Bolt.new
• Email writer tool ke liye ek AI API key (OpenAI ya Anthropic) chahiye hogi, taake tool asli email likh sake.
Step 2: Tool ka prompt (Claude ya Lovable mein paste karein)
Build a modern, mobile-friendly single-page website called "MailCraft AI" with a free AI email writer tool.

Requirements:
1. Hero section with the headline "Write Professional Emails in Seconds" and a short subheading.
2. Tool section with these inputs: email type (job application, follow-up, complaint, thank you, business proposal, resignation, leave request), tone (formal, friendly, persuasive, polite), recipient name, and a text box for key points.
3. A "Generate Email" button that calls an AI API and shows the result in a box with a "Copy" button and a "Regenerate" button.
4. Clean design, white background, blue accent color, large readable fonts.
5. Header navigation: Home, Blog, About, Contact, Privacy Policy.
6. Footer with links to Privacy Policy, Terms, About and Contact.
7. Fast loading, SEO friendly, proper title tag and meta description, and semantic HTML.
8. Keep the API key in a secure backend or serverless function, never in frontend code.

Step 5: Article ka prompt (har topic ke liye baar baar use karein)
Write a detailed, original, helpful article of 1000 to 1200 words on the topic: "[TOPIC HERE]".

Rules:
- Target audience: students and working professionals in the US and UK.
- Use a clear H1 title, then H2 and H3 headings.
- Start with a short introduction that directly answers the question.
- Include at least 2 real, ready-to-use email examples or templates.
- Include a short tips list and a common mistakes section.
- End with a short FAQ section of 3 questions.
- Write in a natural, human, conversational tone. Avoid generic filler and repeated phrases.
- Use British or American English as appropriate.
- Mention the free MailCraft AI email writer tool once, naturally, near the end.
